## ✦ ABOUT PHANTOM-X ✦

**PHANTOM-X** is a powerful multi-device WhatsApp bot designed to provide enhanced functionality, automation, and useful tools for WhatsApp users.

Built with **Node.js** and **Baileys Multi-Device**, PHANTOM-X is designed to be easy to customize, deploy, and extend with your own commands and features.

> 🚀 Create your own WhatsApp bot and unlock endless possibilities with PHANTOM-X.

---

## ✦ KEY FEATURES ✦

- 🔥 Multi-Device WhatsApp Support
- 🤖 Automated Responses
- 📱 Group Management
- 🎵 Media Downloader
- 🔐 Session Management
- ⚡ Fast & Lightweight
- 🧩 Plugin / Command System
- 🛠️ Easy Customization
- 🌐 Multiple Deployment Platforms
- 💻 Open Source & Customizable

## ✦ REQUIREMENTS ✦

Before deploying PHANTOM-X, make sure you have:

- 📌 Node.js v16 or newer
- 📌 Git
- 📌 WhatsApp Account
- 📌 MongoDB if required by your bot version
- 📌 A supported Node.js hosting platform

# ✦ QUICK START ✦

## 1. Clone The Repository

bash
git clone https://github.com/AmonTech1/PHANTOM-X.git
cd PHANTOM-X

> Replace the repository URL above if your repository uses a different name.




---

2. Install Dependencies

npm install


---

3. Configure The Bot

Create or edit your configuration/environment file according to the bot version.

Example:

BOT_NAME=PHANTOM-X
OWNER_NAME=Demon Lord Amon
PREFIX=.


---

4. Start The Bot

npm start

Or:

node index.js

✦ 🚀 DEPLOYMENT ✦

PHANTOM-X can be deployed on several Node.js hosting platforms.


---

<img src="https://cdn.simpleicons.org/render" width="22"> RENDER

Deploy PHANTOM-X easily using Render.

Steps

1. Push your PHANTOM-X source code to GitHub.


2. Open Render.


3. Create a new Web Service.


4. Connect your GitHub repository.


5. Select your PHANTOM-X repository.


6. Set the build command:



npm install

7. Set the start command:



npm start

8. Add your required environment variables.


9. Click Deploy.
